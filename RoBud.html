Current Concept

Robot Buddy (RoBud for short) is a concept project i'm currently gathering resources for. The idea stems from the original project I had hoped to develop for my Final Year Project at Staffordshire, by combining Computer Vision with a Robotic Platform.
This project would combine my knowledge from both degrees - Software and Computer Vision from Staffordshire, and Mechanical/Electrical/Design Engineering from Leeds. I plan on beginning with a smaller, simpler design to test the viability and assess any limitations, but ultimately I would love to create a life-size R2D2 model capable of following me around! The biggest challenges I can forsee in a larger model would be its balance and camera angle. If using a fish-eye lense for wider camera coverage, the CV model would also have to be trained on similar images.
It's a project i've wanted to undertake since I was young, and now I finally feel as though my skills have caught up to where it's something I can make!
So far, I have acquired a 3D Printer and a SolidWorks license so I can print any structure or components I need for the project. I still need a Raspberry PI for the brain, alongside a decent camera module for the live-video tracking.
